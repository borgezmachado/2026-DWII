## 📁 Estrutura do Repositório

| Pasta / Arquivo | Conteúdo |
|-----------------|----------|
| `01_projetoPHP-01/` | Primeiro projeto em PHP (introdução e conceitos básicos) |
| `02_projetoPHP-02_refatorado/` | Projeto PHP reformulado e estruturado com includes e banco de dados |
| `├── includes/` | Arquivos e componentes modulares reutilizáveis (Ex: cabeçalho, rodapé) |
| `├── sql/` | Scripts de criação e população do banco de dados SQL |
| `├── admin.php` | Página de administração do sistema |
| `├── catalogo.php` | Exibição e listagem do catálogo de produtos/itens |
| `├── contato.php` | Formulário de contato para os usuários |
| `├── detalhe.php` | Visualização detalhada de um item específico do catálogo |
| `├── index.php` | Página inicial (Home) do projeto refatorado |
| `├── login.php` | Tela de autenticação e login de usuários |
| `├── logout.php` | Encerramento da sessão ativa do usuário |
| `├── obrigado.php` | Página de agradecimento após envio de formulários |
| `├── painel.php` | Painel de controle restrito após a autenticação |
| `├── projetos.php` | Área de exibição e gerenciamento de projetos |
| `└── sobre.php` | Página institucional com informações sobre o projeto |
